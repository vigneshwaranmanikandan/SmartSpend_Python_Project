# SmartSpend – Personal Expense, Budget & Spending Analyzer

A Python console application that does more than record expenses. It analyzes
spending patterns, tracks budgets, detects unusually high expenses, predicts
possible budget overruns, and generates monthly reports.

## Features

- Add, update and delete expenses
- Search expenses
- Persistent JSON storage
- Monthly budget management
- Category-wise spending analysis
- Budget utilization and warnings
- Projected monthly spending
- Rule-based unusual expense detection
- Smart spending recommendations
- Undo the latest transaction using a stack
- Lambda-based sorting
- Monthly text report generation
- Exception handling and input validation

## Concepts demonstrated

## How to run

1. Install Python 3.10+.
2. Open a terminal in the SmartSpend folder.
3. Run:

```bash
python main.py
```

No external packages are required.

## Project idea

The project addresses a common problem: people can record their spending but
often do not understand where their money goes or whether their current
spending pattern will cause them to exceed their budget.

SmartSpend converts raw transactions into useful insights.
